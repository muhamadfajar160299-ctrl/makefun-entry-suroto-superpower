Entry for the make.fun competition
[u-suroto-worst-superpower-461dcdbe](https://make.fun/bounty/u-suroto-worst-superpower-461dcdbe):
invent the most useless superpower in one line of at most 140 characters.

`main.py` (standard library only) copies the one-line entry in `entry.txt`
byte for byte to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

Run it with:

```sh
python3 -S main.py
```
